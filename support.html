Support

If you need help with Bloom Blocks, please use one of the options below.

Before contacting support

  • Make sure you are using the latest version of the App from the store.
  • Restart the App and your device if the game behaves unexpectedly.
  • If ads fail to load, check your network connection and try again later.

Contact

Email support:

InnoAppDesign@yandex.com

You can also open a support request on GitHub Issues:

https://github.com/aakhmadievvll-cyber/BloomBlocks-Legal/issues

Please include:

  • Your device model and operating system version.
  • The Bloom Blocks app version.
  • A short description of the problem and steps to reproduce it.
  • Screenshots only if they do not contain private information.

Privacy questions

For privacy-related requests, email InnoAppDesign@yandex.com with “Privacy” in the subject line. Please do not include sensitive personal information in public GitHub issues.
